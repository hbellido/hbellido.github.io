<h2>CSS Basics</h2>
<p>Now, let’s dive into the basics of CSS, including selectors, properties, and how to apply styles to HTML elements.</p>

<p>Selectors are used to target HTML elements and apply styles. Some common selectors include:</p>
<ul>
<li><strong>Element Selector</strong>: Targets all instances of an element (e.g., <code>p</code> for paragraphs).</li>
<li><strong>Class Selector</strong>: Targets elements with a specific class (e.g., <code>.example</code>).</li>
<li><strong>ID Selector</strong>: Targets an element with a specific ID (e.g., <code>#header</code>).</li>
</ul>

<p>Selectors are used to target HTML elements and apply styles. Some common selectors include:</p>
<ul>
<li><strong>Element Selector</strong>: Targets all instances of an element (e.g., <code>p</code> for paragraphs).</li>
<li><strong>Class Selector</strong>: Targets elements with a specific class (e.g., <code>.example</code>).</li>
<li><strong>ID Selector</strong>: Targets an element with a specific ID (e.g., <code>#header</code>).</li>
