9:T58cf,<h1>Introduction to TypeScript</h1>
<p>TypeScript is a powerful, statically typed superset of JavaScript that adds optional static types, interfaces, and more to the language. It's designed to help developers build large-scale applications with more reliability and easier code maintenance.</p>
<h2>Why Learn TypeScript?</h2>
<ol>
<li><strong>Type Safety</strong>: Catch errors early during development.</li>
<li><strong>Improved IDE Support</strong>: Better autocompletion, navigation, and refactoring tools.</li>
<li><strong>Enhanced Code Quality</strong>: With TypeScript, your code is more predictable and easier to debug.</li>
<li><strong>Seamless JavaScript Integration</strong>: TypeScript is a superset of JavaScript, so all JavaScript code is valid TypeScript code.</li>
</ol>

<h2>Basic Types</h2>
<p>TypeScript introduces several basic types that JavaScript developers might already be familiar with, but with added type annotations:</p>
<ul>
<li><strong>Boolean</strong>: <code>let isDone: boolean = false;</code></li>
<li><strong>Number</strong>: <code>let decimal: number = 6;</code></li>
<li><strong>String</strong>: <code>let color: string = "blue";</code></li>
<li><strong>Array</strong>: <code>let list: number[] = [1, 2, 3];</code></li>
<li><strong>Tuple</strong>: <code>let x: [string, number]; x = ["hello", 10];</code></li>
<li><strong>Enum</strong>: <code>enum Color {Red, Green, Blue};</code></li>
<li><strong>Any</strong>: <code>let notSure: any = 4; notSure = "maybe a string instead";</code></li>
<li><strong>Void</strong>: <code>function warnUser(): void { console.log("This is a warning message"); }</code></li>
<li><strong>Null and Undefined</strong>: <code>let u: undefined = undefined; let n: null = null;</code></li>
</ul>

<ol>

<h2>Basic Types</h2>
<p>TypeScript introduces several basic types that JavaScript developers might already be familiar with, but with added type annotations:</p>
<ul>
<li><strong>Boolean</strong>: <code>let isDone: boolean = false;</code></li>
<li><strong>Number</strong>: <code>let decimal: number = 6;</code></li>
<li><strong>String</strong>: <code>let color: string = "blue";</code></li>
<li><strong>Array</strong>: <code>let list: number[] = [1, 2, 3];</code></li>
<li><strong>Tuple</strong>: <code>let x: [string, number]; x = ["hello", 10];</code></li>
<li><strong>Enum</strong>: <code>enum Color {Red, Green, Blue};</code></li>
<li><strong>Any</strong>: <code>let notSure: any = 4; notSure = "maybe a string instead";</code></li>
<li><strong>Void</strong>: <code>function warnUser(): void { console.log("This is a warning message"); }</code></li>
<li><strong>Null and Undefined</strong>: <code>let u: undefined = undefined; let n: null = null;</code></li>
</ul>
